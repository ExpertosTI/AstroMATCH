# Marca

Autor de la aplicación: Brainiac X. Estos valores ya están en la app. Diseño los respeta; no propone otra paleta para Match.

## Color

| Nombre | Hex | Uso |
|---|---|---|
| Void | `#0F0707` | Fondo del teléfono |
| Void arriba | `#130713` | Degradado |
| Void abajo | `#391708` | Degradado |
| Hueso | `#EAE0CE` | Texto |
| Violeta | `#952C91` | Brillo y acento |
| Violeta brillo | `#B03AD8` | Brillo |
| Brasa | `#F4572E` | Kicker, bordes, acción |
| Brasa brillo | `#FF6D1D` | Brillo |
| Oro | `#E2B340` | Precio del stand |
| Tinta | `#0B0708` | Texto sobre brasa |

## Tipo

- Títulos: **Climax**.
- Interfaz: **Gotham Medium**.
- Gotham Book y Gotham Bold aparecen en el arte de marca y viven en Adobe Fonts. No se suben aquí.

## Forma

- Iconos en rejilla de 24.
- Trazo base hueso, acento brasa.
- Esquinas cortadas, no redondas. El botón y la tarjeta usan un corte diagonal.

## Atmósfera

Siempre detrás del contenido, en este orden: fondo void, brillo violeta arriba a la izquierda, brillo brasa abajo a la derecha, grano encima en overlay. Las máquinas y el logo van delante.

El negro de un PNG se cala. Si el fondo viene pintado, se ve un cuadro sobre el void.
